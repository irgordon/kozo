## Classification Model

Reproduction uses the governed statuses `REPRODUCED`, `NOT_REPRODUCED`,
`INSUFFICIENT_EVIDENCE`, `EXPECTED_BEHAVIOR`, `UNSUPPORTED_SCOPE`, `DUPLICATE`,
`INFRASTRUCTURE_FAILURE`, and `RESOLVED_ON_MAIN`.

User impact is classified independently from release action as `U0` through
`U4`. Release severity is classified as `R0` through `R4`. Only a reproduced,
in-scope `U2`-`U4` defect with `R3` or `R4` severity can authorize patch
preparation.

## Reproduction Results

There were no user-filed cases to reproduce. Hosted acceptance produced one
case, which was reproduced in three controlled observations:

1. Current-main CI run `31127967845` failed in release-bundle verification
   with Odin `dev-2026-08-nightly:902106f`.
2. Immutable-tag CI run `31128097086` failed at the same command and message.
3. The official macOS arm64 `dev-2026-08` compiler produced
   `kernel-build-check.o`; the helper returned exit 1 because it did not check
   that suffix for a suffixless requested path.

The last passing hosted run, `30507221289`, used Odin
`dev-2026-07-nightly:819fdc7`. This version change explains why the accepted
release could pass before the defect became observable.

The controlled release baseline did reproduce the published expectation:

1. All six hosted files downloaded successfully.
2. `SHA256SUMS` validated every listed asset.
3. The archive matched the accepted SHA-256
   `bb74de23e62a87ae26f21252388007822b4764f2cf98626c157f28422dd41897`.
4. Hosted `latest_verify.json` reported pass, 67 checks, and 0 failures.
5. Hosted `release_metadata.json` reported version `1.0.0`, the accepted
   commit, QEMU pass, blocker none, 41 markers, and the accepted license set.
6. The downloaded ISO emitted all 41 ordered markers and ended at
   `KOZO_RUNTIME_RETURN_OK` before the governed timeout.
7. QEMU exit `124` occurred only after the complete accepted sequence and is
   expected terminal-halt behavior for this run.
8. A clean shallow clone of annotated tag `v1.0.0` resolved to the accepted
   target commit with a clean detached worktree.
